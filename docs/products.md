## PmHub

**Java 实战项目与项目管理系统实践**

PmHub 是一个围绕项目管理场景展开的完整实战项目。从需求分析、数据库设计、接口规划到前后端实现，覆盖了一个真实项目从 0 到 1 的完整链路。

在这个项目里，你会看到：

- 如何用 Spring Boot + MyBatis-Plus 搭建企业级后端架构
- 项目管理的业务模型怎么设计（项目、任务、成员、权限）
- 前后端分离的协作方式与接口规范
- 从本地开发到部署上线的完整流程

如果你正在找一个能写进简历、面试时能讲清楚细节的项目，PmHub 是一个不错的起点。

## AI 编程实践

**围绕 AI 辅助开发的工作流、工具和案例**

AI 不是替代程序员，而是放大程序员的产出。这个系列记录我在日常开发中怎么用 AI 工具提效，包括：

- **提示词工程**：怎么写能让 AI 一次给出可用代码的 prompt
- **工作流搭建**：从需求描述 → 代码生成 → 测试验证的完整链路
- **工具对比**：Cursor、GitHub Copilot、Claude Code 各自适合什么场景
- **真实案例**：用 AI 完成的具体功能模块和踩过的坑

适合想系统掌握 AI 编程、而不是只停留在"试试好玩"阶段的开发者。
