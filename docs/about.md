我是一名全栈开发者，主要技术栈是 Java / Spring Boot，同时也做前端和产品。过去几年里，我一直在做这几件事：

- **写代码**：从业务系统到 side project，保持手感
- **做产品**：把技术能力转化为能解决实际问题的产品
- **写内容**：把实践和思考整理成文章，帮别人少走弯路
- **玩 AI**：探索 AI 辅助开发的新工作流，提升效率

我相信 **Language shapes our world** —— 不仅是编程语言，也包括我们表达和思考的方式。
