# 短帖（X）

这里会沉淀短内容、碎片观点、灵感记录和 X/Twitter 风格的更新。

短帖的特点是：轻量、高频、即时。记录我每天的观察、思考和发现。

## 短帖 vs 长文

| | 短帖 | 长文 |
|--|------|------|
| 长度 | 几十到几百字 | 几千字 |
| 频率 | 每天或隔天 | 每周或每月 |
| 目的 | 记录、分享、讨论 | 系统表达、建立认知 |
| 适合 | 快速浏览、获取信息 | 深度阅读、完整理解 |

如果你只想快速了解我在关注什么，看短帖就够了。如果你想深入理解某个话题，去读 [长文](/blog/longform.html)。
